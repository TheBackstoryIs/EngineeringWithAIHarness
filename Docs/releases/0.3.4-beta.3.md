# EWAI 0.3.4-beta.3: a second opinion on coding decisions

This experimental beta adds optional help from Jev and OpenAI Decisions when you are choosing how to approach a piece of work.

- **Weigh your options.** Rank an existing set of choices, or compare an AI's recommended option with a second opinion.
- **Find suitable reviewers.** Get persona suggestions from those already available to your project, including installed premium personas. No extra persona download is required.
- **Try recommendations first.** Shadow mode shows suggestions without changing existing behaviour. Required evidence, tests, reviews and human decisions still apply.
- **Choose whether to use it.** Both providers start off. Add their keys privately through the CLI or dashboard and give separate consent. Adding a key never switches either provider on.

Usage caps and estimated costs help you keep track of the experiment. We are investigating whether this saves time, tokens and model spend; those benefits have not yet been measured on completed coding tasks. OpenAI connection tests used mocks, and human Manual QA remains pending.

Install from the beta channel:

```sh
npm install --save-dev @thebackstoryis/engineering-with-ai@beta
```

For setup and limitations, read the [Jev guide](../operations/jev-beta-experiment.md) or [OpenAI Decisions guide](../operations/openai-decisions-beta.md).
